# Training data (not included)

The dataset is not distributed with this repository. The photos were
collected by hand from enthusiast forums, sales listings and the author's
own pictures, so the author doesn't hold the rights to redistribute most of
them. This file documents the layout the scripts expect, so you can build
your own dataset in the same format.

## Layout

One folder per task, one subfolder per class:

```
train/
├── caroserie/            body style, from rear views
│   ├── berlina/          sedan
│   └── break/            estate
├── model/                variant, from front views
│   ├── 1300/
│   ├── cn3/              1310 CN3
│   └── cn4/              1310 CN4
├── motor/                fuel system, from engine-bay photos
│   ├── carburatie/       carburettor
│   └── injectie/         fuel injection
└── router/               generated by scripts/populate_router.py
    ├── fata/             front   (copy of model/*)
    ├── spate/            rear    (copy of caroserie/*)
    └── motor/            engine  (copy of motor/*)
```

Class names come from the folder names, and empty folders are skipped.

## Vehicle IDs

Evaluation is grouped per vehicle, so every file name has to start with a
vehicle ID: `car<ID>__<original name>`, for example `car0042__03.jpg`. Photos
of the same physical car share the same ID across all tasks. Without IDs,
`train_dinov2.py` falls back to a per-image split and warns that the scores
are inflated.

`scripts/group_vehicles.py propose` suggests groups from DINOv2 similarity.
Review them, then run `scripts/group_vehicles.py apply` to rename the files.
